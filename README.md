# WindowAnchor

一款让窗口听话的 Windows 桌面小工具。

当前版本：v2.0 · Windows 10/11 · 本地优先 · 无需安装

## 它是什么

WindowAnchor 首先是一个窗口置顶工具。它常驻系统托盘，帮你把常用窗口钉在最前面，同时还能做更多：靠边自动收起、一键隐藏、透明度调节。

它不做复杂的窗口管理，也不抢你任务栏的位置。它只解决一个问题：**当你需要一边干活一边盯着某个窗口时，怎么让那个窗口既不碍事、又随时能叫出来。**

它适合带着参考资料写代码、一边看攻略一边打游戏、或者摸鱼的时候随时能把窗口藏起来。

## 主要功能

窗口置顶与辅助：
- 全局热键一键置顶/取消，支持同时置顶多个窗口
- 透明度调节，半透明窗口不挡视线
- 点击穿透，鼠标可以直接穿过去点后面的窗口

靠边自动收起：
- 窗口拖到屏幕边缘停一下，自动收成一条细线
- 鼠标移过去平滑展开，移开自动收起
- 每个置顶窗口可以单独开关，也可以固定收起方向
- 展开后拖动窗口离开边缘，就不会再自动收起了

老板键：
- 按一下瞬间隐藏所有置顶窗口，再按一次恢复
- 隐藏期间托盘图标变红，提醒你现在是"老板模式"
- 可以设置隐藏时同时静音被隐藏的窗口
- 热键可自定义

其他：
- 托盘菜单可撕成独立窗口，方便连续操作
- 设置里可以改快捷键、开关开机自启
- 所有数据都在本机，不上传

## 下载

普通使用者无需下载源代码。请在本仓库右侧的 Releases 中打开最新版本，下载打包好的 exe 即可。

下载后双击运行，右下角托盘会出现一个小图钉图标。

由于个人项目尚未购买代码签名证书，Windows 可能显示 SmartScreen 提示；请确认文件来自本仓库的正式 Release。

## 快速开始

切到想置顶的窗口，按 `Ctrl+Shift+Space`，就置顶了。再按一次取消。

右键托盘图标能看到所有功能：
- 正在置顶的窗口列表，点一下取消置顶
- 对每个置顶窗口，可以单独开靠边收起、调透明度、开关点击穿透
- 打开设置界面，改快捷键、开关开机自启

靠边收起怎么开：
1. 先把窗口置顶
2. 右键托盘图标 → 已置顶窗口列表
3. 点某个窗口的子菜单 → 勾选"靠边收起"
4. 可以选自动检测方向，也可以固定往某一边收

老板键默认是 `Ctrl+Shift+H`，按一下所有置顶窗口瞬间藏起来，再按一次全部恢复。

完整说明见下文的使用细节。

## 数据、隐私与卸载

WindowAnchor 完全在本机运行，不要求账号，不依赖云服务，也不会上传任何数据。配置文件保存在 `%APPDATA%/WindowAnchor/` 下。

右键托盘图标选择"退出"，就关闭了程序。想卸载的话，直接删掉 exe 文件和配置文件夹就行。

## 使用细节

### 热键

- 置顶热键：默认 `Ctrl+Shift+Space`
- 老板键：默认 `Ctrl+Shift+H`
- 都可以在设置里自己改

### 靠边收起

- 拖到边缘停 0.3 秒才会收起，拖着经过不会误触发
- 收起和展开都有平滑动画
- 最大化的窗口不会触发收起
- 展开后拖动窗口离开边缘，就自动取消这个窗口的靠边收起状态；再拖回边缘，会在新位置重新收起
- 固定方向模式下，窗口必须真的靠近那个方向的边缘才会收起，不会在屏幕中间也收

### 老板键静音

老板键隐藏窗口时，可以选择同时静音对应的应用。这个功能需要额外安装 `pycaw` 和 `comtypes`，不装也能用，只是隐藏的时候不会自动静音。

静音是单应用的，只静音被隐藏的窗口对应的进程，其他应用正常播放。

### 托盘菜单

- 托盘菜单顶部有个小图钉图标，拖动它可以把菜单"撕"成独立窗口
- 撕下来的菜单不会自动关闭，方便你连续操作多个窗口
- 托盘菜单里点按钮操作不弹通知，避免遮挡菜单；用热键操作时才弹通知

## 从源代码运行

需要：

- Windows 10/11 x64
- Python 3.10+
- 安装依赖：`pip install -r requirements.txt`

运行：

```bash
pythonw windowanchor.pyw
```

想带控制台看报错就用：

```bash
python -m windowanchor
```

自己打包 exe：

```bash
pyinstaller --clean WindowAnchor.spec
```

或者直接双击 `build.bat`，打完在 `dist/WindowAnchor.exe`。

## 项目状态与后续方向

v2.0 是第二个公开版本，当前重点是把置顶、靠边收起、老板键这三个核心功能做稳，而不是扩展成复杂的窗口管理器。

后续可能探索：

- 多显示器支持
- 窗口贴靠分屏（类似 Win+方向键）
- 置顶窗口分组
- 特定程序启动时自动置顶的规则

这些方向是探索地图，不代表固定排期。

## 项目背景

WindowAnchor 起源于一次 Vibe-coding 实践：从对 Windows 自带置顶功能的不满开始，经过自己天天用、反复改，逐渐加上了靠边收起、老板键这些功能。

它不以成为全能窗口管理工具为目标，而尝试回答一个更具体的问题：**当你需要一边干活一边盯着某个窗口时，怎么让那个窗口既不碍事、又随时能叫出来？**
